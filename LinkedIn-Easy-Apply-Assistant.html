Easy Apply Assistant Privacy Policy

Last updated: 2026-02-06

Overview

Easy Apply Assistant helps users fill LinkedIn Easy Apply forms using profile data entered by the user. The extension runs locally in the browser.

Data Collection

The extension does not collect, transmit, or sell personal data to the developer or any third party. It does not use external analytics or ad trackers.

Data Storage

Profile and answer data entered in the popup is stored in chrome.storage.local on the user's device to support form filling. This storage is local to the browser profile.

Third-Party Sharing

No user data is shared with third parties by the extension developer.
